# Wanderlust

**Explore More, Worry Less!**

Wanderlust is a responsive travel and tourism website where visitors can explore popular destinations, browse travel packages, discover must-visit attractions and send a trip enquiry. It is a student project built to practise HTML, CSS and JavaScript.

Live demo: https://your-project-name.vercel.app

---

## Features

- Hero banner with a welcome message and an "Explore Now" button
- Popular destination cards for Goa, Jaipur and Bali
- Travel packages showing duration, price and what is included
- List of must-visit attractions
- Enquiry form with built-in validation and a thank-you message
- Smooth navigation to every section
- Responsive layout that works on different screen sizes
- Semantic HTML for better accessibility and SEO
